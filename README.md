# StudyFlow

StudyFlow is a small app for keeping track of homework. Add a task, pick a subject and due date, and mark it done when you finish.

## What it can do

- Add, finish, and delete tasks
- Sort tasks by subject or status
- See how many days are left (or how late a task is)
- Undo a delete
- Save tasks in your browser
- Use dark mode on phones or computers

When you add a task, the date starts as today. The app also remembers your last subject and priority to make adding more tasks quicker.

## Run it

Open `index.html` in your browser. That's it. No install or account needed. Your tasks stay saved in that browser.

## Files

- `index.html` – the page
- `style.css` – how it looks
- `script.js` – how it works

## Made with

HTML, CSS, and JavaScript.
