# StudyFlow

A simple web app that helps students organize homework by subject, priority and due date. Built with plain HTML, CSS and JavaScript — no frameworks, no backend.

## The problem

Students juggle homework from many subjects and often only notice a deadline when it is already too late. Paper lists and generic to-do apps don't show *how urgent* a task is, and accidental deletions or repetitive typing make them annoying to use. StudyFlow keeps everything in one clean list and makes urgency obvious at a glance.

## Quality-of-life improvements

1. **Smart due-date hints** – tasks show "Due today", "Due tomorrow", "Due in 3 days" or "Overdue by 2 days", and overdue tasks get a subtle red edge.
2. **Undo delete** – instead of an annoying "Are you sure?" popup, deleting shows a short message with an **Undo** button.
3. **Fast task entry** – the due date starts as today, the form remembers your last subject and priority, and the cursor returns to "Task name" after each task, so you can add several tasks in a row.

## How to use

1. Download or copy the `studyflow` folder.
2. Open `index.html` in your browser (double-click it).
3. Add your first task. Your data stays in your browser, even after closing it.
